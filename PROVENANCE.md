# Provenance and licence

This is an engineering inventory, **not legal advice**: where each part of the code came from, so a reviewer can
check it.

## Licence

**GNU GPL version 2 only** (`COPYING`; SPDX `GPL-2.0-only` in the sources). The RTL8821AE chip code derives from
Realtek's Linux drivers that carry "version 2 ... no later version", so the drivers can only be distributed under
GPLv2. The RTL8821CE back end derives from Linux rtw88, which Realtek licensed "GPL-2.0 OR BSD-3-Clause"; it is used
here under the GPL-2.0 option.

## Not linked

No IBM library or header; the only run-time imports are `DosOpen`, `DosClose`, `DosRead`, `DosDevIOCtl` from
`DOSCALLS`. No Open Watcom run-time code is in the binary (`-zl`, `nodefaultlibs`).
