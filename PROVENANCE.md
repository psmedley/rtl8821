# Provenance and licence

This is an engineering inventory, **not legal advice**: where each part of the code came from, so a reviewer can
check it.

## Licence

**GNU GPL version 2 only** (`COPYING`; SPDX `GPL-2.0-only` in the sources). The chip code derives from Realtek's Linux
drivers, which carry "version 2 ... no later version", so the driver can only be distributed under GPLv2.

## Sources

| File(s) | Origin |
|---|---|
| `src/os2/*`, `src/wlan/*`, `tests/*`, `install/RTWMAC.CMD` | the iwlwifi OS/2 driver ([psmedley/iwlwifi](https://github.com/psmedley/iwlwifi), GPL-2.0-only). Its OS/2 plumbing derives from the RTL88EU driver of [OS2World/DRV-NET-RTLUSBWifi](https://github.com/OS2World/DRV-NET-RTLUSBWifi) via the QCA6174 driver, its station from the QCA6174 driver. Changed here: names and texts (`drv.h`, `genmac.c`, `ndis.c`, `strat.c`), the BAR selection and 8/16-bit MMIO (`pci.c`, `lib.asm`, `os2dd.h`), the `hw_cmd` debug hook (`dbg.c`, `hw.h`) |

## Not linked

No IBM library or header; the only run-time imports are `DosOpen`, `DosClose`, `DosRead`, `DosDevIOCtl` from
`DOSCALLS`. No Open Watcom run-time code is in the binary (`-zl`, `nodefaultlibs`).
